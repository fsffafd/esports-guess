# 电竞竞猜系统

## 快速开始

1. 确保已安装 Node.js (https://nodejs.org)
2. 解压此文件夹
3. 打开命令行，进入 esports-guess 目录
4. 运行: npm install
5. 运行: node server.js
6. 打开浏览器访问: http://localhost:3000

## 默认管理员账号

- 用户名: admin
- 密码: admin123

## 功能

- 比赛竞猜：投注比赛胜负，赢家按比例分池
- 锦标赛预测：冠军(x20)、亚军(x10)、季军(x7)、四强(x4)、八强(x3)、出线(x2)
- 排行榜：按积分排名
- 管理后台：http://localhost:3000/admin

## 技术栈

- Node.js + Express
- SQLite (sql.js)
- PWA 支持（可安装到手机/桌面）
